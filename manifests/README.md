# Manifiestos

`source_files.json` registra archivos usados en la prospección, tamaño y SHA-256.
Los originales no están en Git y los checksums no son enlaces de descarga.

El paquete final de entrenamiento y demo deberá tener un manifiesto distinto con:
identificador, URL compartida, licencia, versión, escena/fecha, bandas, CRS,
transformación, máscara de calidad, split, tamaño y SHA-256. No inventar una URL
de Drive/Kaggle antes de crear y verificar ese recurso.
